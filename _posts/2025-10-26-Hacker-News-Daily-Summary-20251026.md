### 3. The Linux Boot Process: From Power Button to Kernel

 Score: 223 Comments: 49 [Link](https://www.0xkato.xyz/linux-boot/)

 > When you press the power button, the CPU starts in real mode and executes firmware (BIOS/UEFI) which loads a bootloader like GRUB. The bootloader then loads the Linux kernel into memory, which includes a small setup program. This setup program switches the CPU from real mode to protected mode and then to 64-bit long mode. Finally, the compressed kernel is decompressed, relocated if necessary, and the main kernel initialization begins.

### 30. An Efficient Implementation of SELF (1989) [pdf]
