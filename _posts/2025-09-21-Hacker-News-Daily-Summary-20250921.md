### 9. In defence of swap: common misconceptions (2018)

 Score: 59 Comments: 39 [Link](https://chrisdown.name/2018/01/02/in-defence-of-swap.html)

 > Swap is not just emergency memory but a crucial mechanism for equal memory reclamation, allowing the system to efficiently manage both anonymous and file-backed pages. Disabling swap doesn't prevent disk I/O under memory pressure; it merely shifts thrashing to file pages, potentially reducing efficiency. Modern kernels (4.0+) handle swap better, and proper tuning with tools like cgroup v2's `memory.low` can optimize performance. Overall, swap promotes healthier system operation by expanding reclaimable memory options.
