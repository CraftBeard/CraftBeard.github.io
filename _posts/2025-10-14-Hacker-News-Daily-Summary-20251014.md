### 6. Copy-and-Patch: A Copy-and-Patch Tutorial

 Score: 37 Comments: 5 [Link](https://transactional.blog/copy-and-patch/tutorial)

 > Copy-and-patch compilation is a fast baseline JIT technique that generates native code by copying pre-compiled code fragments called stencils. These stencils are minimal C functions with relocation holes for constants or addresses. At runtime, the JIT copies these stencils into executable memory and patches the holes with specific values. This approach requires minimal assembly knowledge and produces efficient code quickly. The tutorial demonstrates creating a JIT that specializes and executes `1 + 2` using this method.
