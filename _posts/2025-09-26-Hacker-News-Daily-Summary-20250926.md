### 25. Writing Memory Safe JIT Compilers

 Score: 40 Comments: 12 [Link](https://medium.com/graalvm/writing-truly-memory-safe-jit-compilers-f79ad44558dd)

 > GraalJS achieves memory safety in JIT compilation by using the Truffle framework, which implements language semantics only once in a memory-safe Java interpreter. Through partial evaluation (the first Futamura projection), the Graal compiler automatically transforms this interpreter into optimized machine code for hot functions. This approach eliminates memory safety bugs by ensuring the compiled code exactly matches the interpreter's behavior. Consequently, GraalJS avoids the security vulnerabilities common in traditional VMs that implement semantics separately in both interpreter and JIT compiler.
