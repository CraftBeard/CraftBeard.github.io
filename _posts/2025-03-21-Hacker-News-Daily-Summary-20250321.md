### 16. History of Null Pointer Dereferences on macOS

It highlights how earlier macOS versions on Intel architectures allowed attackers to exploit NULL dereferences by mapping memory at address zero, but modern mitigations on Apple Silicon, such as strict NULL page mapping protections, hardware execution controls (PXN/PAN), Pointer Authentication Codes (PAC), and the removal of 32-bit support, have rendered these vulnerabilities unexploitable.
