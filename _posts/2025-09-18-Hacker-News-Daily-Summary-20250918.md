### 22. Rendezvous Hashing Explained (2020)

 Score: 13 Comments: discuss [Link](https://randorithms.com/2020/12/26/rendezvous-hashing.html)

 > Rendezvous hashing is a distributed hashing algorithm that maps keys to servers by generating a unique, random priority list of servers for each key and selecting the server with the highest hash value. It provides excellent load balancing and avoids cascaded failures during server outages by distributing a failed server's load across the remaining servers. A key disadvantage is its O(N) lookup time, which makes it suitable for small to medium-sized systems. It is particularly well-suited for cache systems that can eventually satisfy its "first choice" invariant automatically.
